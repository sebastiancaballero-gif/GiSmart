  oculta o muestra cada tipo y cada nivel de cubierta. Flechas del sentido

  mouse, modo oscuro, trace animado.
- Red de fibra -> Hilos, seccion feeder: ODF (con bandeja y puerto), OLT
  (tarjeta y puerto) y equipo destino de cada hilo, sacados del trace.
- Ficha "Informacion": los codigos con su nombre de los catalogos de la
  base (CORNING (CORN), Cubierta de nivel 2 (NAP) (CUB_N2)...).
- Que nada se quede pegado: tope de espera en las capas (60 s) con un
  reintento automatico si la base falla de paso; Imprimir y Copiar mapa ya
  no se quedan esperando si una tesela del mapa base no baja; topes en el
  inicio de sesion y en la busqueda de direcciones.
- Dependencias: nueva jspdf (para el PDF de empalmes) y se corrigieron 9
  avisos de seguridad (pnpm audit) en paquetes internos de Next. Cambia
  pnpm-lock.yaml (ver paso 5).
Probado completo con Node 18.18.0 en modo produccion (instalacion congelada,

directa y con bandejas, y el PDF), entradas y salidas, hilos (las dos

ANTES DE EMPEZAR (en el servidor, en PowerShell)
------------------------------------------------
1. Ver la version de Node:
       node -v
   Tiene que decir v18.18.0 o mas nueva (v18.19, v20.x, v22.x sirven).

2. Ver que pnpm sea la 10:
       pnpm -v
   Si no esta o es otra: npm install -g pnpm@10


INSTALAR ESTA VERSION (copiando el paquete)
-------------------------------------------
1. Detener el servicio:
       nssm stop GISmart

2. Respaldar la carpeta actual (por si hay que volver atras):
       Copy-Item C:\apps\GISmart C:\apps\GISmart-respaldo -Recurse

3. Borrar SOLO estas carpetas del servidor (se reemplazan completas):
       app, components, hooks, lib, modulos, public, scripts, docs, .next
   (hooks es nueva en esta version; si no existe, no hay nada que borrar).
   Si el servidor tiene una version anterior a la 1.11.1, borrar tambien
   node_modules (en la 1.11.1 cambiaron Next, Supabase y pnpm).
   NO borrar: .env.local, logs.

4. Descomprimir el .zip y copiar su contenido dentro de C:\apps\GISmart
   (que los archivos queden en C:\apps\GISmart\app, C:\apps\GISmart\.next, ...).

5. Instalar dependencias (en esta version hay una nueva, jspdf, y cambian
   algunas internas de Next, asi que este paso SI hay que hacerlo):
       cd C:\apps\GISmart
       pnpm install --frozen-lockfile
   Un aviso de "Ignored build scripts: core-js" es normal: no hace falta.

6. Solo si el .env.local del servidor tiene variables NEXT_PUBLIC_TESELAS_...
   (proveedor del mapa base), volver a compilar, porque esas variables quedan
   fijas al compilar y este paquete se compilo sin ellas:
       pnpm run build
   Si no las tiene, la carpeta .next del paquete sirve tal cual.

7. Arrancar el servicio:
       nssm start GISmart

Actualizar con "git pull" todavia no sirve: estos cambios no estan subidos
a GitHub. Usar el paquete.
